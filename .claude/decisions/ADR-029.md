# ADR-029 — A guest on the adopter's page: it costs nothing at rest, and trusts nothing it is given

- **Status:** Proposed — the owner asked for it in session, 2026-09-23 ("it's important that we keep a
  small bundle, I don't want our solution to be responsible for breaking the adopter app, or reducing
  drastically the performance of the web app … make sure we have a secure solution, I don't want our
  interface to be the reason of some random vulnerability"); this text awaits acceptance
- **Date:** 2026-09-23
- **Deciders:** Andre, Architect
- **Relates to:** [ADR-021](./ADR-021.md) (one folder, nothing installed); [ADR-026](./ADR-026.md) (the
  panel, the companion, hiding an adopter's own launcher); [ADR-028](./ADR-028.md) (the sparse index);
  Rule 8 (no remote host), Rule 17 (a role's registry is its entitlement).

## Context

The widget runs inside an application someone else wrote, on every page, for every visitor. Two kinds
of cost land on that application rather than on us, and until now neither had a rule.

**Performance, measured 2026-09-23 on the committed build.**

- The orb's canvas was drawn at its largest size (320 CSS px, ×2 device pixels = a 640×640 backing
  store, 409,600 pixels) even while docked at 92 px — about 12 times the pixels anyone could see — and
  redrawn at every other animation frame for as long as the page stayed open.
- The closed full-screen view kept its CSS animations running, off screen.
- `create()` fitted the hashing encoder synchronously while the adopter's page was still starting.
- The bundle was 59.0 KB gzipped, about 18 KB of it CSS carried as template strings with every space,
  comment and newline intact.

**Security.** The widget turns data into actions on the adopter's page. An audit of every such sink
found five that trusted what they were handed:

| Sink | What reached it unchecked |
|---|---|
| `a.href`, `location.assign`, the adopter's `navigate` | A registry route, a filled template or a `homes` entry: `javascript:…`, `//evil.example`, `/\evil.example` (a browser reads `\` as `/`) |
| The rule that hides an adopter's own launcher (ADR-026) | A selector from options: `x { } body { display: none }` writes any CSS into the page |
| The bundle's base URL | `data-nextgen-base` pointing at another site: registries, and the whole assistant, from a host the adopter does not control |
| The merged enum map | A registry whose JSON has a `"__proto__"` key, merged with `Object.assign` |
| The question box | No length limit: a pasted 5 MB string is tokenised on the main thread |

None of these was exploited; each needs a registry, an option or an attribute the adopter already
controls. But a registry is a file on a server, an attribute can be injected by an unrelated bug, and
"only the adopter can do that" is the assumption that turns an adopter's small mistake into our
vulnerability.

## Decision

We will treat the adopter's page as a place we are a guest in: **at rest the widget costs next to
nothing, and nothing it is given becomes an action until it has been checked.**

**Performance.**

1. The canvas is drawn at the size it is shown (`liquid.setResolution`): it grows at once when the panel
   opens, and shrinks 820 ms after it closes, so the transition never shows a blurred frame.
2. At rest, docked, one frame in four is drawn, and after 12 s (60 s when open) none: one last frame
   stays on screen. Any state change, sound level, pointer or focus on the orb wakes it (`wake()`).
3. Every animation inside the closed screen is paused (`animation-play-state: paused`).
4. The encoder is fitted lazily: on `requestIdleCallback` (at most 3 s), or on the first question,
   whichever comes first. A shipped index still needs no fit at all.
5. The CSS in `assistant.ts`, `widget.ts` and `beam.ts` is minified at build time by esbuild's own CSS
   minifier (`minifyStylesheets` in `packages/embed/build.mjs`). Interpolations are held in place by
   marker rules, and the build fails if a marker is lost, rather than shipping a broken stylesheet.
6. A question is capped at 500 characters (`MAX_QUESTION`), in the input box and again in `route()`.

**Security.**

7. **Every destination is a path on this site.** `safeRoute()` (in `present.ts`) accepts a string only
   if it starts with a single `/`, has no `\` and no control characters, is at most 2,048 characters,
   and resolves to the same origin as a fixed base. Everything that becomes an `href`, a
   `location.assign` or a call to the adopter's `navigate` goes through it: answers, choices, home
   routes, links and the legacy `mount` widget. An unsafe choice is dropped, and an unsafe destination
   is never moved to. What the visitor reads in its place is the answer's text without the move — not
   yet pinned by a test.
8. **The launcher-hiding selector is a selector.** Rejected: an empty string, anything over 200
   characters, `{ } ; @ <`, a comment opener, or a backslash. A rejected selector hides nothing.
9. **The bundle loads from this site.** `load()` refuses a base URL on another origin (a `StartError`,
   the `nextgen:error` event, nothing fetched), unless the adopter supplies their own `fetch`, and with
   it the decision.
10. **Maps built from registry keys have no prototype.** Enum maps are `Object.create(null)`, and a
    merge copies them key by key.
11. Nothing the widget renders reaches `innerHTML` except constant icons compiled into the bundle.
    Every text from a registry, a companion or the visitor is `textContent`.

## Measured

On the committed build, 2026-09-23:

| | Before | After |
|---|---|---|
| Bundle, gzipped | 59.0 KB | 57.2 KB (with the checks in 7–10 added) |
| Docked canvas backing store | 640×640 = 409,600 px | 184×184 = 33,856 px |
| Docked, at rest | 30 fps, for as long as the page stays open | 15 fps for 12 s, then 0 |
| Closed screen's CSS animations | running | paused |
| Encoder fit | during start-up, synchronous | idle time, or the first question |
| What an end user downloads (family fixture, one role) | — | about 66 KB gzipped: widget, registry, index, thresholds |

Every gate passes except `router-floor`, which is the known, non-blocking floor. Decisions on the golden
set are unchanged (generated-golden, derived-artefacts).

## Alternatives considered

**Do nothing.** The widget worked, and Pilot-A never reported the cost. But a 640×640 canvas redrawn
forever is a laptop fan on a page that should be idle, and the security sinks are each one bad file
away from being exploited. Rejected, because the cost falls on the adopter, who cannot see it coming.

**Stop the orb entirely at rest from the first frame.** This is the cheapest option. Rejected: the
orb's slow movement is how a visitor notices the assistant is there (the owner chose the "alive" look).
Twelve seconds at a quarter of the frame rate keeps that, and costs a fraction.

**Sanitise routes by stripping bad characters.** Rejected: a sanitiser that changes a route sends the
visitor somewhere nobody declared. Refusing moves nobody anywhere, which is always safe.

**An allowlist of routes (only those in the registry).** Rejected as the only check: the search
template and parameters filled from the URL legitimately produce routes not listed verbatim. A
same-origin path check covers every source with one rule. That the path exists is the router's job.

**A CSS-in-JS runtime, or shipping a separate `.css` file.** A runtime adds weight to save weight. A
separate file costs one more request, and a `<link>` that a strict CSP must allow. Minifying at build
time keeps constructed stylesheets, which a strict CSP already allows, and costs no runtime code.

**Minify with a regex instead of esbuild.** Rejected: a stylesheet has strings, `url()` and escapes. A
regex that is almost right ships a broken style to every adopter. esbuild is already the build tool.

## Consequences

- **A legitimate cross-origin bundle now needs code.** An adopter who serves registries from a CDN on
  another host must pass their own `fetch` to `load()`. The script-tag one-liner cannot do it. That is
  deliberate, but it is a step, and it is documented only in the embed README.
- **A route that is not a plain path is refused, even when the adopter meant it.** A hash-router app
  (`#/players`) or a route to a sibling subdomain will not navigate from the assistant. Hash routes are
  the likely one. If an adopter needs them, `safeRoute` must learn `#/` deliberately, not be bypassed.
- **A selector with a backslash is refused.** CSS escapes (`#a\:b`, needed for Tailwind-style ids) cannot
  be used to hide a launcher. The adopter must use another selector, such as an attribute or class.
- **The orb can look still.** After 12 s at rest it freezes on its last frame. A visitor who expected it
  to keep breathing may read that as broken. It wakes on hover or focus, not on page scroll.
- **The first question can pay for the fit.** If no idle period comes and there is no shipped index, the
  fit runs on the first question: a one-time delay of about 0.4 s at 2,000 screens (ADR-028).
- **The CSS minifier is a build step that can fail.** It is guarded by the marker check. A stylesheet
  whose shape the plugin does not recognise (a new `const X = css\`…\``) is shipped unminified, silently.
- **Five checks mean five places to keep.** A new sink (a new way to navigate or write CSS) is
  protected only if whoever adds it knows this ADR exists. The tests pin the known sinks, not new ones.
