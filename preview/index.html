The widget, on pages it did not design

The same built nextgen.js an adopter serves, on host pages of different shapes. This is where to judge how it looks and where it places itself; the bench is where to judge what it decides.

  • Bench — ask, and see the whole trace: which stage decided, what else it considered, by what margin, and how long each stage took.
  • The mock application — every route in the generated registry is a real page, so when the assistant navigates it lands somewhere that exists and the orb is waiting there. Switch role from the sidebar.
  • Plain — a host page with no CSS at all.
  • Themed, left nav — declares its own --nextgen-accent; the orb should wait on the right.
  • Themed, right nav — the mirror image; the orb should wait on the left.
  • Phone frame — narrow viewport.

Voice. The microphone works on localhost. Speech becomes text only where the browser can do that on the device; elsewhere the orb still reacts to your voice and asks you to type. That is Rule 8, not a limitation of the bench.

Every role's bundle is served here, which production must never do (Rule 17) — a role's registry is its entitlement. This directory is never exported.
